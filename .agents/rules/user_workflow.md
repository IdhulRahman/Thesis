# User Workflow Rules

1. **Immediate Documentation Updates on VM Configuration Changes:**
   Whenever a significant update or configuration change is made (especially on VM-3, VM-4, VM-5, or OAI configurations), update the corresponding documentation files (such as `docs/vm/vm3-oai-5gc.md`, `docs/troubleshooting.md`, etc.) immediately before proceeding further to prevent omissions.

2. **Consistent English Documentation:**
   All technical and VM documentation must strictly use English as the primary language, maintaining repository consistency and standard terminology.

3. **Observer Consultation with Concrete Evidence:**
   When encountering complex or architectural issues, formulate clear, structured questions and status reports to be submitted to the observer/reviewer. Always attach concrete, untruncated empirical evidence (exact log excerpts, JSON responses, command outputs, timestamps).
